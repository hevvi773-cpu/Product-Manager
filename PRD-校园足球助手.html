1.2 产品定位

一句话定义：面向校园足球队的 AI 辅助决策与社交平台，帮助队长管人、管赛、管复盘，帮助队员约球、社交、看球。

差异化：不是传统的球队管理工具，而是 "AI 队长"——在赛前预测、赛后复盘、阵容推荐等场景中嵌入 AI 能力，让数据驱动球队决策。

二、市场与用户分析

2.1 市场规模与背景

校园足球是中国足球人口的重要组成部分。根据教育部统计数据，全国普通高校数量超过 3000 所，以平均每校 20 支院队、每队 25 人计算，全国校园足球参与者规模达到 150 万人以上。这是一个被主流体育产品忽视的长尾市场。

西南大学层面：全校 40 余个学院，30+ 拥有独立球队，核心活跃用户约 500 人，泛足球爱好者约 1500-2000 人，分散在多个微信/QQ 群中，缺乏统一管理工具。

为什么值得做？
① 稳定的周期性（校内联赛/友谊赛/毕业季）→ 稳定回访
② 用户集中、画像清晰 → 冷启动容易
③ 数据价值高（比分/进球/助攻/出场）→ 数据闭环
④ 现有工具无法满足需求

2.2 目标用户

角色画像核心痛点频率
队长大三/大四，责任心强排阵靠经验、约人靠接龙、复盘靠感觉每周3-4次
队员大二/大三状态无法及时同步、缺少个人数据每周2-3次
爱好者不限年级找不到球友、不了解赛事信息每周1-2次

2.3 用户故事

  • 作为队长，我想看到 AI 推荐的阵容和战术，让排阵有数据支撑
  • 作为队长，我想一键发布阵容并通知全员，而不是在群里@所有人然后被刷屏
  • 作为队员，我想一键标记状态（可上场/轻伤/缺阵），队长排阵时能看到
  • 作为队员，我想在广场找到约球、约饭、看球的局
  • 作为普通学生，我想看到全校各院队的排名和战绩

核心竞品深度分析

① 微信/QQ群（最大竞争对手）——所有球队都在用，但问题是 信息不沉淀、不结构化、不可检索。策略：不是替代，而是补充微信群无法提供的结构化管理和AI能力。

② 懂球帝——用户是"职业足球球迷"而非"校园球队队长"。策略：不走资讯路线，走工具+社交路线。

③ 传统球队管理工具——界面陈旧、无AI、无社交。策略：AI能力+社交广场，差异化竞争。

3.2 功能详情

F1：AI赛前预测 P0 MVP

首页顶部置顶大卡片，渐变背景差异化视觉。输入对手历史数据+本队球员状态，输出预测比分/胜平负概率/战术建议/推荐阵容。

为什么是MVP功能？ AI能力最直观的体现，队长决策时最需要的参考信息。

F2：阵容管理 P0 MVP

可视化球场阵型图，球员按位置排列，颜色标识状态（🟢可上场/🟡轻伤/🔴缺阵/🚫停赛），一键发布通知全员。

为什么是MVP核心？ 队长最高频使用的功能，是产品被"用起来"的关键。

F3：赛后复盘 P0 MVP 亮点功能

三层结构：🤖AI数据复盘 → 👥队员感想 → 🎯队长总结 → 🤖AI综合总结（✅亮点/⚠️待改进/🔮下场建议）。赛后数据→录入→回传模型→改善未来预测。

为什么是亮点？ 所有球队都在做但都做不好的事。AI自动生成结构化总结，降低队长工作量。

F4：广场 P1

分类Tab（约球/约饭/看球/闲聊），结构化卡片展示时间/地点/人数，悬浮发布按钮+底部弹窗表单。

F5：个人状态标记 P0 MVP

队员赛前标记状态（🟢可上场/🟡轻伤/🔴缺阵），自动同步到阵容管理页。从"队长填鸭式管理"到"队员自主参与"。

四、AI 能力规划

4.1 为什么校园足球需要 AI？

历史比赛数据可以有效预测未来比赛结果。比赛结果与首发阵容、对手实力、主客场、近期状态高度相关，可通过AI模型学习。

  • 赛前预测：从模糊的"上次交手"记忆 → 数据驱动的对手分析
  • 赛后复盘：从口头说两句 → 结构化、可追溯、可沉淀的复盘报告
  • 阵容推荐：从"多个选择"困境 → AI辅助决策参考

4.2 能力矩阵

AI能力阶段数据需求技术方案验证状态
赛前比分预测P0两队历史战绩、进球/失球XGBoost/时序预测✅ 已验证 61.4%
阵容推荐P0球员状态、历史表现规则引擎+排序模型待开发
赛后数据复盘P0控球/射门/传球统计+规则推理已规划
AI综合总结P0数据复盘+感想+队长总结LLM总结已规划
对手弱点分析P1对手历史比赛数据特征分析+NLP下一阶段
球员表现趋势P1球员历史出场数据时间序列分析下一阶段
智能约球匹配P2位置偏好+空闲时间推荐算法远期规划

4.3 AI能力详细说明

能力一：赛前比分预测

输入：两队历史交锋、近期战绩、进球/失球、球员可用状态
输出：预测比分、胜平负概率、战术建议
技术：XGBoost多分类，15维滚动窗口特征，严格时序切分防泄露

已验证：QQ空间爬取6年349条记录，清洗343条，三分类准确率61.4%，主队胜预测77.1%，优于基线4.1个百分点。

能力二：阵容推荐

规则引擎（位置覆盖+状态可用性）生成候选阵容 → 排序模型（球员历史表现）排序 → 输出最优+备选方案。队长有最终决定权。

能力三：赛后数据复盘

统计计算（各项vs历史均值）+ 规则推理（自动生成洞察）。示例："本场控球率46%，低于赛季均值58%，中场控制力不足"。

能力四：AI综合总结

输入：数据复盘结论 + 队员感想 + 队长总结 → LLM整合 → 三段式：✅亮点 / ⚠️待改进 / 🔮下场建议。

4.4 数据闭环

赛前数据（对手分析）→ AI 预测 → 阵容推荐 → 比赛执行
                                                                        ↓
赛果录入 ← 赛后数据复盘 ← AI综合总结 ← 队员感想 + 队长总结
      ↓
回传模型（增量学习）→ 下一轮预测更准确 🔄

预测越准 → 用户越信任 → 数据越多 → 模型越准 → 正反馈循环
